# QUALIFY AI v0.4 – 参考問題登録＋ChatGPT予想問題生成

## 使い方
1. 「参考問題＋予想問題」タブで資格を選択し、参考問題のPDF・画像・文書などを選びます。
2. 「ChatGPTに資料を渡す」を押し、iPhoneの共有シートでChatGPTを選びます。共有できない場合はChatGPTを開き、資料を添付して指示文を貼り付けます。
3. ChatGPTに、参考問題の抽出と予想問題の生成を依頼します。JSONファイルとして出力してもらいます。
4. アプリに戻り「ChatGPTの結果を取り込む」でJSONを選択します。参考問題は参考問題集へ、予想問題は問題演習用の問題集へ登録されます。

## データ
- 参考問題は `referenceQuestions` に保存し、通常の問題演習には含めません。
- 予想問題は `questions` に `origin: "AI予測問題"` として保存します。
- 参考問題と予想問題は「参考問題＋予想問題」画面で区別して確認できます。予想問題は問題管理から編集・削除できます。
- 端末のブラウザ内（localStorage）に保存されます。ブラウザデータ消去・別端末移行に備え、定期的にJSONバックアップを行ってください。

## 注意
- ChatGPTアプリへの資料共有や回答の自動返却は、iOS・ChatGPTアプリの共有対応に依存します。ChatGPTからアプリへ結果を直接自動返送することはできないため、生成JSONをアプリで選択して取り込む手順が必要です。
- 参考問題は資料の内容を確認して登録してください。公式過去問であるかどうかは、出典資料で確認してください。
- アプリ内のサンプル問題は学習用オリジナル例題で、公式過去問ではありません。
