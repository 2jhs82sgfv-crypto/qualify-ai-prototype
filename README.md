# QUALIFY AI prototype v0.1

## できること
- 資格モジュールの登録（複数資格を同じ問題エンジンで管理）
- 問題の追加・削除
- ○×・選択式の演習、採点、解説表示
- 学習履歴の簡易記録
- JSONバックアップ・インポート
- PWAのService Workerによる静的ファイルのキャッシュ

## 起動方法
PWAとしてオフライン利用するにはHTTPSで公開する必要があります。
このフォルダを静的ホスティング（例：Vercel / Netlify / GitHub Pages）へ配置してください。
公開URLを一度オンラインで開くと、以後キャッシュ済みの画面はオフラインでも開けます。
ブラウザのローカルストレージに学習データが保存されます。ブラウザデータを消去すると失われるため、定期的にJSONバックアップしてください。

## 現時点の制限
- AIによる自動Web検索・問題生成は未接続。ChatGPTで作成したJSONを取り込む方式を先行実装。
- 画像/PDF OCR、複数端末同期、ログイン、サーバーDBは未実装。
- サンプル問題は動作確認用のオリジナル例題で、公式過去問・公式予想問題ではありません。正答・解説は公式資料や現行規格と照合して利用してください。
- 大型特殊：普通免許所持者は神奈川県の案内上、学科試験免除対象。技能試験・教習要件を確認してください。
